# Cognitive Sentinel Turret 🛡️🎯

An autonomous security turret system integrating computer vision and dynamic sensor-based override protocols.

## Author
* **Mohannad Emad Khaloof** - *Initial Work & Architecture*

## Features
* **Hand Tracking Control:** Real-time gesture control using MediaPipe & OpenCV (Python).
* **Hardware Override:** Dynamic threshold trigger using Ultrasonic, Vibration, and Sound sensors (Arduino).
* **Serial Communication:** JSON-encoded data pipeline between Python host and MCU.
